# VibeMap roadmap

## Beta gate

- [ ] Complete migration from Express JWT to NextAuth/session auth
- [ ] Add Ghost Mode and audience controls
- [ ] Add account deletion and data export
- [ ] Add privacy policy, consent copy and age policy
- [ ] Add auth/API integration tests and CI
- [ ] Add error monitoring, backups and dependency auditing
- [ ] Test the mobile geolocation flow on real devices

## Focused product loop

- [ ] Personal mood memory timeline
- [ ] Approximate neighbourhood pulse without exposing names
- [ ] Friend requests with `pending`, `accepted` and `blocked` states
- [ ] A return reason: streaks or “one year ago” memories

## Later experiments

- [ ] Realtime updates by map viewport
- [ ] Time Travel mood history
- [ ] Place recommendations
- [ ] Challenges and lightweight achievements
- [ ] PWA install and offline shell
- [ ] Music and wearable integrations

Ideas stay here until validated with 10-20 real users. The MVP should remain centred on one reliable loop: share a feeling, discover the atmosphere, return to remember it.
